### share
```
########################################
#                                      #
# Информация включено ли               #
#  подключение к тор                   #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
#                                      #
########################################
# share>     командная строка          #
########################################
```

1. `run-tor` поднимает тор демона, на время подключения лочит ввод команд и показывает прогрес подключения в реальном времени, можно остановить клавишей esc
2. `stop-tor` поднимает тор демона, на время подключения лочит ввод команд и показывает прогрес подключения в реальном времени, можно остановить клавишей esc
3. `receiving-data` включает режим получения данных (поднимает onion сервер). так же блокирует прием команд, в реальном времени печатает полученные серверы и чаты. можно остановить клавишей esc
4. `share-data` включает отправку данных пользователю, после появляется выбор пользователя (списком), после выбор сервера и чата. передается сервер и чат. выернуться назад esc
